# מחשבון תעריף מדידות ומיפוי

אשף לחישוב שכר טרחה למדידות ומיפוי, לפי ״תעריף תכנון מסילות״ של רכבת ישראל, מהדורה 13.3.5 (ינואר 2025), פרק 3.

בוחרים סעיפים (3.2 עד 3.7), ממלאים כמויות, מצמידים למדד ומקבלים ניתוח שכר כולל מע״מ, עם אפשרות הדפסה.

**לפתיחה:** https://ezylevy.github.io/survey-quote/

כל המחירים נמצאים בבלוק `PRICES` בראש `index.html`, וליד כל מחיר מספר הסעיף בתעריף.
המחירים בתעריף צמודים למדד המחירים לצרכן של ינואר 2016.
